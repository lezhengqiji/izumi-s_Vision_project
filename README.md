# izumi-s_Vision_project
a simple vision project for anime character
这是我用yolo11制作的一个动漫人物识别项目，由于资源太少，可能准确信较低，敬请谅解
本项目所用的模型是用python在anaconda创建的虚拟环境中编写
##使用指南：
将装有图片的文件夹地址地址复制到detect.py中result行中的地址，之后点击运行即可


##如果你想改进，使其更加准确：
       增加训练图片：请自行配置datasets文件夹，并用labelimg标注
       修改训练模型：请在train.py的model行中修改所用模型


##如果遇见问题：
       可以运行test03.py查看问题所在
